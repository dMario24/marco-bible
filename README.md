# 가톨릭 성경 (marco-bible)

[한국천주교주교회의 『성경』](https://bible.cbck.or.kr/Knb)을 모바일에서 편하게 읽기 위한 Next.js 앱입니다.

## 기능

- **모바일 최적화 본문 보기**: 명조체 본문, 글자 크기 조절, 스크롤하면 상단 바 숨김, 좌우 스와이프로 이전/다음 장 이동
- **이어 읽기**: 화면에 보이는 절 위치를 자동 저장하고, 홈·하단 탭에서 그 절로 바로 이동
- **읽음 기록**: 장 끝까지 읽고 20초 이상 머물면 자동 기록, 버튼으로 직접 표시·해제
- **읽기 통계**: 전체·구약·신약 진도, 연속 읽기 일수(최장 기록 포함), 18주 읽기 달력, 최근 14일 막대그래프, 책별 진도, 완독한 책
- **기록 백업**: 기록은 브라우저(localStorage)에 저장되며, JSON 파일로 내보내거나 불러올 수 있음

## 실행

```bash
npm install
npm run dev
```

본문은 요청이 올 때 원 사이트에서 장 단위로 가져와 파싱한 뒤 서버에 캐시합니다(`lib/knb.ts`, `'use cache'`).

### 크롤링 (선택)

오프라인으로 쓰거나 원 사이트 요청을 줄이려면 미리 받아 둘 수 있습니다. 받은 파일은 `data/knb/{책}/{장}.json`에 저장되고, 앱은 로컬 파일을 먼저 사용합니다.

```bash
npm run crawl            # 전체 1,328장 (요청 간 0.5초 간격, 약 15분)
npm run crawl -- Mt Mk   # 특정 책만
```

## 저작권

성경 본문의 저작권은 한국천주교중앙협의회에 있습니다. 크롤링한 `data/`는 `.gitignore`에 포함되어 있어 저장소에 올라가지 않습니다. 본문을 일반에 공개하는 서비스로 배포하려면 먼저 한국천주교중앙협의회의 허락을 받으세요.
